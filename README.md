# Личный 2-летний трекер аспирантуры

Сжатый roadmap на базе официального ИПРА (4 года → **окт 2026 — сен 2028**) + локальное Streamlit-приложение с **сохранением прогресса в SQLite**.

## Быстрый старт

**Локально:** двойной клик по `Start.bat` в этой папке.  
Откроется окно сервера и браузер. Чтобы остановить — закройте окно.

**В облаке (ссылка без запуска):** см. [DEPLOY.md](DEPLOY.md) — Streamlit Community Cloud + GitHub.

Через командную строку:

```powershell
cd "c:\Users\Admin\YandexDisk\Spall Fracture things\PHD 2026\План работы в аспе\phd_tracker"
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Адрес локально: http://localhost:8501

## Что внутри

| Путь | Назначение |
|------|------------|
| `data/plan_seed.json` | Начальный план: 4 фазы, ~32 задачи, подзадачи |
| `data/progress.db` | Ваш прогресс (создаётся при первом запуске) |
| `app.py` | UI |
| `src/db.py` | SQLite CRUD |
| `src/viz.py` | Дашборд и таймлайн (Plotly) |

## Экраны

1. **Дашборд** — общий %, фазы, категории, просрочки и ближайшие дедлайны  
2. **План / задачи** — фильтры, статус, %, заметки, чеклист подзадач (всё пишется в БД)  
3. **Таймлайн** — Gantt фаз и задач  
4. **Статьи и диссертация** — 3 статьи, 4 блока текста (~25%), конференции  
5. **Данные** — экспорт JSON-бэкапа, сброс к seed (нужно ввести `RESET`)

## Персистентность

- При первом запуске seed загружается в `progress.db`.  
- Дальше приложение **читает БД**, а не seed.  
- Пока файл `data/progress.db` на месте (и синхронизируется через Яндекс.Диск), прогресс не теряется.

## Важно

Это **личный** трекер. Официальные дедлайны ИПРА/аттестаций в вузе остаются отдельными «жёсткими» датами в задачах и не заменяются этим планом.
